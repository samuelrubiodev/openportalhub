## What AGPL-3.0 means here

You may use, study, modify and redistribute this software, including for
commercial purposes. The one condition that matters for a web application is
section 13: if you run a modified version and let anyone interact with it over
a network, you must offer those users the Corresponding Source of your version,
under the same license.

In practice, if you run this software as-is (or with changes you are happy to
publish), you are compliant. Pointing users at this repository is enough.

## Commercial license

If your use cannot meet the AGPL obligations, a **commercial license** is
available. This is the intended path for anyone who wants to run a modified,
closed-source version as a network service, or who simply cannot accept the
AGPL in their organization.

A commercial license removes the source-sharing obligation and is granted per
project. To request terms, write to:

**legal@openportalhub.org**

OpenPortalHub is the sole copyright holder of the code in this repository, so
it can offer both licenses.
